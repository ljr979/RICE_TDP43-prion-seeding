# RICE_TDP43-prion-seeding

Code and analysis scripts used to generate figures and statistical analyses for the manuscript "ALS-associated mutations in the TDP-43 C-terminal domain alter in vitro aggregation kinetics but not prion-seeding in a cell model".

This repository contains two main types of data:

1. figure-level input tables used to reproduce manuscript panels directly
2. example input and output files for stepwise analysis pipelines, so readers can inspect the expected file formats and run the analysis scripts without relying on local hardcoded paths

## `input_data/`

This folder contains data that scripts read directly.

For the figure-generation scripts in `src/Figure_*`, the `input_data/Figure_X/` folders contain the processed tables used to reproduce the final manuscript panels.

For the stepwise analysis scripts in `src/Figure_1/data_analysis/`, the `input_data/Figure_1/data_analysis/` subfolders contain example inputs for each script. These are intended to document expected file formats and allow readers to run each step independently.

Current example analysis input layout for Figure 1:

```text
input_data/Figure_1/data_analysis/0_process_raw/
    rep_3_raw_data.csv
    rep_3_plate_map.csv

input_data/Figure_1/data_analysis/1_fit_curves/
    1_change_in_intensity_plus_info.csv

input_data/Figure_1/data_analysis/3_visualise_params/
    fit_parameters.csv
```

## `output/`

This folder contains files generated by the scripts in this repository.

At the figure level, `output/Figure_X/` contains exported panel graphics and any associated processed summary tables.

At the analysis-pipeline level, `output/Figure_1/data_analysis/` contains example outputs corresponding to each script in the Figure 1 ThT fluorescence workflow.

Current example analysis output layout for Figure 1:

```text
output/Figure_1/data_analysis/0_process_raw/
    1_processed_raw.csv
    1_change_in_intensity_plus_info.csv
    *_change-in-intensity.png

output/Figure_1/data_analysis/1_fit_curves/
    clean_for_fitting.csv
    fit_parameters.csv
    no_fit.csv
    fitted_curve_*.svg
    fitted_curve_*.png

output/Figure_1/data_analysis/3_visualise_params/
    tlag_plot_all.svg
    tlag_plot_all.png
    elongation_rate_plot_all.svg
    elongation_rate_plot_all.png
```

## `src/`

This folder contains all Python scripts used for data processing, plotting, and analysis.

### `src/Figure_1/`

These scripts generate Figure 1 panels and associated supplementary plots.

### `src/Figure_1/data_analysis/`

This folder contains the stepwise analysis pipeline used to process raw ThT fluorescence plate-reader data.

#### `0_process_raw.py`

Reads raw plate-reader output and a matching plate map, converts the data into treatment-resolved tables, and writes processed fluorescence traces for downstream analysis.

Expected example inputs:

1. `input_data/Figure_1/data_analysis/0_process_raw/rep_3_raw_data.csv`
2. `input_data/Figure_1/data_analysis/0_process_raw/rep_3_plate_map.csv`

Primary outputs:

1. `output/Figure_1/data_analysis/0_process_raw/1_processed_raw.csv`
2. `output/Figure_1/data_analysis/0_process_raw/1_change_in_intensity_plus_info.csv`

#### `1_fit_curves.py`

Fits constrained Boltzmann-style models to processed fluorescence traces and exports lag phase, elongation rate, and fit-quality metrics.

Expected example input:

1. `input_data/Figure_1/data_analysis/1_fit_curves/1_change_in_intensity_plus_info.csv`

Primary outputs:

1. `output/Figure_1/data_analysis/1_fit_curves/fit_parameters.csv`
2. `output/Figure_1/data_analysis/1_fit_curves/no_fit.csv`
3. `output/Figure_1/data_analysis/1_fit_curves/fitted_curve_*.svg`

#### `3_visualise_params.py`

Generates bar-and-dot visualizations of fitted lag phase and elongation-rate parameters across seeding conditions.

Expected example input:

1. `input_data/Figure_1/data_analysis/3_visualise_params/fit_parameters.csv`

Primary outputs:

1. `output/Figure_1/data_analysis/3_visualise_params/tlag_plot_all.svg`
2. `output/Figure_1/data_analysis/3_visualise_params/elongation_rate_plot_all.svg`

## Notes For Reuse

Readers using these scripts on new datasets should check and, if necessary, update:

1. expected input filenames
2. treatment naming conventions encoded in sample identifiers
3. optional analysis toggles at the top of each script
4. whether example output generation is enabled, for example `savefig=True` in plotting scripts
